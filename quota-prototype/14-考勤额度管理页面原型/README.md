# 假期额度页面原型

本原型用于评审“假期额度”二级菜单下的完整页面结构、字段和操作归位。页面视觉遵循 HR One 轻量运营页风格，业务结构以本次确认的菜单为准。

## 页面结构

```text
假期额度
├─ 假期余额
│  ├─ 余额汇总
│  ├─ 余额明细
│  └─ 已休明细
├─ 调休假明细
│  ├─ 年度汇总
│  ├─ 周期汇总
│  └─ 日明细
├─ 年假结算
│  ├─ 结算汇总
│  └─ 结算明细
├─ 病假结算
└─ 调休假结算
   ├─ 结算汇总
   └─ 结算明细
```

## 关键口径

- `假期余额`是统一查询和额度维护入口，`余额汇总`回答员工各假期类型当前还有多少，`余额明细`回答某个假期类型、年度额度如何组成。
- `已休明细`放在`假期余额`页面内；一张原休假单及其变更只展示一行，仍有额度使用结果时进入列表，全部恢复后不展示。
- `已休明细`中的列表字段命名为`使用明细`，行操作命名为`查看使用明细`；不展示底层扣减/恢复过程字段，不展示“使用状态”和“休假结果”。`休假记录`中的原休假单和已生成恢复明细的变更单均可点击跳转。
- `查看使用明细`弹窗通过表格展示，一条已休记录可对应多行额度来源数据；已经全部恢复的来源不展示。
- 整单销假产生全部额度恢复明细后，该原休假单不在`已休明细`展示。历史记录没有可靠额度来源时，不进入新版`已休明细`。
- `余额汇总`只展示本次重构范围内的年假、病假、调休假，不默认展示婚假等非本期额度类型。
- `余额汇总`增加`总可休额度（h）`，取年假、病假、调休假当前可休额度之和，`—`按 0 计算。该值仅用于汇总展示，不表示不同假期类型之间可以互换额度。
- `余额明细`原型为方便需求编写，展示默认字段和可选字段全集；正式落地时可通过列设置区分默认展示和可选展示。
- `调休假明细`保留现有 OEHR 的年度汇总、周期汇总、日明细三种粒度；调休调整、延期、导入调整仍以日明细为处理对象。
- `年假结算`和`调休假结算`保持现状的汇总/明细结构和字段差异，不合并为统一结算页。
- `病假结算`单独成页，承接病假现有离职结算、撤销结算和结算结果字段，避免把病假专属结算按钮放进通用余额明细。

## 操作归位

- 余额汇总：查询、导出、导出设置。
- 余额明细表头：计算额度、导入额度、导入调整额度、批量操作、导出、导出设置。
- 余额明细行操作：年假/病假支持额度调整、额度延期、日志；调休假进入调休假明细。
- 结转有效期作为列表字段直接展示，不再点击打开侧栏或弹窗。
- 额度调整弹窗：按截图口径收敛为假期类型、员工、当前可休额度、调整值、调整后可休额度、调整原因；弹窗默认两列展示，调整原因独占一行。
- 批量调整额度：不展示“已选择多少人”，只展示操作必要字段。
- 额度延期弹窗：按截图口径收敛为假期类型、员工、结转有效期、当年有效期/余额有效期、调整原因；展示出的有效期字段按必填处理。
- 调休假日明细：额度调整、额度延期、日志、批量调整额度、批量延期、导入调休假调整。
- 年假结算：过期结算、离职结算、撤销结算、导出、导出设置。
- 病假结算：离职结算、撤销结算、导出、导出设置。
- 调休假结算：余额结算、离职结算、撤销结算、导出、导出设置。
